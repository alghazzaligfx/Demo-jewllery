# Nooré Jewels — Website Demo

A responsive jewellery-house website concept created by Al Ghazali GFX.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — mobile navigation and collection filters
- `assets/` — original SVG jewellery illustrations

## Image/content rule
All visuals in this demo are original SVG illustrations of jewellery objects only: ring, necklace, earrings, bracelet and pendant. No people, women, men, faces, hands, bodies, animals or other living beings are included. No external image URLs are used.

## Publish on GitHub Pages
1. Upload all files and the `assets` folder to the root of the `Demo-jewellery` repository.
2. In repository Settings → Pages, choose `Deploy from a branch`.
3. Select branch `main` and folder `/ (root)`, then Save.
4. Wait for GitHub Pages to deploy.
